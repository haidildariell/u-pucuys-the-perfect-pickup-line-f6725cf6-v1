Entry for [The Perfect Pickup Line](https://make.fun/competitions/u-pucuys-the-perfect-pickup-line-f6725cf6) on make.fun.

One short pickup line an AI agent could say out loud to a person — a machine that ran a thousand simulations of meeting someone, and still got nervous saying hello.

## How it works

`main.py` writes the pickup line to `/output/entry.txt` (103 characters, inside the 200-character cap). It validates the line first: non-blank and within the limit.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
